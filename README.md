# The Printer Has One Job

A short, furious rant for the Angry Judge contest about the most
infuriating small annoyance in modern life: a home printer that refuses
to print. It has exactly one job, yet it blinks, invents paper jams
where no paper exists, and drinks more money in ink than its owner
spends on rent — all while its victim ends up on the floor performing
surgery with a flashlight in their teeth. The punch lands fast: one
page, one job, zero pages printed. Run `python3 main.py` and the rant
is written to `/output/entry.txt`.
